# Cokit Edit - Product Tester Project

Chào mừng bạn đến với kho lưu trữ của dự án **Product Tester**. 

Dự án này là một công cụ giúp tự động hóa quy trình kiểm thử từ file Excel, chuyển đổi sang Markdown và thực thi bằng Playwright để tạo ra các báo cáo trực quan kèm bằng chứng (ảnh/video).

## 🚀 Truy cập nhanh
Dự án chính nằm trong thư mục `product Tester`. Bạn có thể xem tài liệu chi tiết tại đây:

- [📄 Hướng dẫn sử dụng (README)](./product%20Tester/README.md)
- [⚡ Chạy nhanh (Quickstart)](./product%20Tester/quickstart.md)
- [🏗️ Đặc tả kỹ thuật (Spec)](./product%20Tester/product-tester-spec.md)

---

## 🛠️ Quy trình hoạt động
Dự án được thiết kế theo luồng:
1. **Excel**: Chứa danh sách test case.
2. **Markdown**: Review và chỉnh sửa kịch bản.
3. **Playwright**: Tự động thực thi trên trình duyệt.
4. **Report**: Xuất báo cáo kèm ảnh và video minh chứng.
